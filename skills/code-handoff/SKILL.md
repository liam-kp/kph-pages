# code-handoff — KPH addendum

**Note on scope:** this file is a KPH-specific reference doc, not the actual `code-handoff` skill implementation (that skill is a bundled Claude Code system skill with no editable file found on this machine — see `brain/LOG.md` 2026-07-05 entry). This file documents the one addition KPH sessions must carry in every task.md this skill generates, mirroring the pattern of `brain/skills/firebase-schema-truth-check/SKILL.md`.

## Mandatory final step

Every task.md generated by `code-handoff` for a KPH session MUST end its step list with:

```
N. Append LOG.md entry + git commit/push
   - Append one entry to `brain/LOG.md` (top of file, newest-first) per the format header in that file.
   - `git add`/`commit`/`push` the LOG.md update together with (or immediately after) the task's own commit.
   - This is the FINAL step — do not close the session before it lands.
```

## Why this exists

`brain/LOG.md` (KPH Unified Operations LOG, 2026-07-05) is the one journal every Claude Code session writes to regardless of which project/spoke initiated it. A task.md that ends at "done" without this step reproduces the "invisible zombie session" problem (FU-MADUZEN012) — work that happened but left no trace any other session could find. See `brain/INSTRUCTIONS_CORE.md` § LOG discipline.
